# Changelog

## 0.2.1

- Added a distinctive plum-and-crimson Equipment frame to the ten cursed cards, with separate hover and selected states.

## 0.2.0

- Added seven pieces of equipment, bringing the Blacksmith roster to ten distinct cursed items.
- Added original pixel-art sprites for each new item inside the game's native card borders.
- Colored the entire Curse line red for all ten items.

## 0.1.0

- Added Cracked Spellglass, Bitter Chalice and Cracked Duelist’s Mirror to native item selection and the Blacksmith.
- Added paired Gift and Curse descriptions, custom pixel-art item icons, and native inventory persistence for the initial local playtest.
