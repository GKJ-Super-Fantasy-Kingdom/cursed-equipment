# Cursed Equipment 0.2.1 release assets

The [repository README](../README.md#screenshots) uses local image paths. The [Thunderstore Details draft](../thunderstore/DETAILS.md#screenshots) uses public HTTPS paths following the sibling GKJ releases.

The individual PNGs are unscaled crops of the native Blacksmith rendered at 1.5× with Cursed Equipment 0.2.1. The full [1× mixed row](screenshots/0.2.1/mixed-1x.png) and [1.5× mixed row](screenshots/0.2.1/mixed-1p5x.png) show Bitter Chalice between the ordinary Sword and Bow with controller focus on the Chalice price.

The planned public base is `https://raw.githubusercontent.com/GKJ-Super-Fantasy-Kingdom/cursed-equipment/v0.2.1/docs/screenshots/0.2.1/cards/`. All ten image requests returned HTTP 404 during local verification. They need a public repository and a published `v0.2.1` ref containing the assets before the Thunderstore draft will render them. No publication was performed.
