# Changelog

## 0.2.4

- Updated the Thunderstore logo with a brighter crimson seal and plum shading inside the copper frame.

## 0.2.3

- Shared the Cursed Relics 0.2.8 artwork and native focus treatment for cursed cards. Added more clearance around Gift and Curse text and kept signed percentages together when a line wraps.
- Redrew all ten item icons on the game's 16 × 16 pixel grid with compact silhouettes and thin outlines. The Blacksmith and native ground drops use the same sprites.
- Added the original copper-framed, cursed breastplate package logo.

## 0.2.2

- Matched the Blacksmith's native card size and corner rounding in every state, with plum rails, crimson corner inlays, a cracked smith's seal, and an ivory focus edge.

## 0.2.1

- Added a distinctive plum-and-crimson Equipment frame to the ten cursed cards, with separate hover and selected states.

## 0.2.0

- Added seven pieces of equipment, bringing the Blacksmith roster to ten distinct cursed items.
- Added original pixel-art sprites for each new item inside the game's native card borders.
- Colored the entire Curse line red for all ten items.

## 0.1.0

- Added Cracked Spellglass, Bitter Chalice and Cracked Duelist’s Mirror to native item selection and the Blacksmith.
- Added paired Gift and Curse descriptions, custom pixel-art item icons, and native inventory persistence for the initial local playtest.
